## 🥇 方案 1：Zeabur（国内原生，最推荐）

### 官网
https://zeabur.com

### 优点
- ✅ 服务器在香港/新加坡，国内访问极快
- ✅ 支持微信/手机号注册
- ✅ 中文界面，操作简单
- ✅ 支持 GitHub 一键部署
- ✅ 免费额度 $5/月（跑一个 Flask 足够）

### 部署步骤

1. **注册登录**：打开 zeabur.com → 微信扫码登录
2. **新建项目**：点击「新建项目」→「部署新服务」
3. **选择部署方式**：
   - 如果有 GitHub：选「从 GitHub 导入」
   - 没有的话：选「上传代码」或「Docker 镜像」
4. **选择运行环境**：
   - 如果是 GitHub 导入：自动检测到 Python
   - 如果手动：选 Docker，使用我们项目里的 Dockerfile
5. **配置启动命令**：
   ```
   pip install -r requirements.txt && PORT=8080 python server.py
   ```
6. **配置端口**：`8080`（或者用系统分配的 `$PORT`）
7. **绑定域名**：Zeabur 会自动给一个免费的域名

## 🥈 方案 2：Railway.app（国内访问快）

### 官网
https://railway.app

### 优点
- ✅ 国内节点，访问快
- ✅ GitHub 一键登录
- ✅ 每月 $5 免费额度
- ✅ 自动检测 Python 项目

### 部署步骤

1. 打开 railway.app → Login with GitHub
2. New Project → Deploy from GitHub repo
3. 选择你的 viimk-uniapp 仓库
4. 选择 Python 模板（或者让它自动检测）
5. 在 Variables 里添加：
   ```
   PORT = ${{ PORT }}
   ```
6. Start Command 设置为：
   ```
   pip install -r requirements.txt && python server.py
   ```
7. 等待部署完成，会给一个域名

## 🥉 方案 3：Hugging Face Spaces（100% 免费）

### 官网
https://huggingface.co/spaces

### 优点
- ✅ 国内可访问
- ✅ 完全免费，没有额度限制
- ✅ 支持 Docker

### 部署步骤

1. 注册 Hugging Face 账号
2. 创建 Space：
   - Space name: `viimk-api`
   - License: MIT
   - **Space SDK**: 选 **Docker**
   - **Docker Template**: Blank（空模板）
3. 进入创建好的 Space → Files
4. 上传以下文件：
   - `server.py`
   - `requirements.txt`
   - `Dockerfile`（项目里已创建好）
5. 等待构建完成，Space 运行起来后，在 Space 设置里复制域名
6. 访问：`https://你的用户名-viimk-api.hf.space/api/health`（注意 HF 的域名格式）
